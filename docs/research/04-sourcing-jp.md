## 一句結論

Year 1 的日本渠道，本質是**旅客藥妝店 + 集運／行李箱**，不是批發。松本清、Welcia、Sundrug、Donki 的免稅是給**非居民個人攜出**；Donki 明文：**轉售／商務用途不合資格，免稅單據不開發票**。你不會在第一年拿到花王、資生堂、KOSE、FANCL 的正式出口帳戶。CPTPP 原產地證明在 CAD 10–20 的萬寧式貨上**通常永遠不值得追**。防曬你可以當人買；**公司不得商業賣進加拿大**。100V 電器：預購 + 警告，或**直接砍**——不要軟話。

## 何時跳過萬寧、改飛／改訂日本（唯一一段香港）

同一週、同一 SKU：只有當**落地後仍便宜到蓋過摩擦**，才離開香港貨架。摩擦 = 機票攤分或代運費堆疊 + 時間 + 無發票 + 無 CoO。萬寧本週有貨且促銷已接近目錄 `landedCad` → **留香港**。觸發日本的只有四種：香港斷貨或根本沒有日版；日本藥妝大減 + 免稅 10% 之後，單位仍明顯低過香港落地；Loft / Hands / Hobonichi 那種香港沒有的限定；SK-II／Decorté 這種 6.5% MFN 開始痛、且你真的有日本出口人肯簽原產地。CAD 21 的 Melano、CAD 24 的 Hada Labo，一件一寄 DHL 會把貢獻吃光——日本網單直寄加拿大**不是**這盤的生存路徑。

## 旅客袋 ≠ 商業進口

日本出口規則與加拿大商業進口，都不是「我手提入關」。

| | 旅客袋 | 公司當生意做 |
| --- | --- | --- |
| 日本消費稅 | 免稅／退稅：非居民、護照、同店同日稅拔 ≥ ¥5,000；消耗品（化妝品、食品、藥）2026-10-31 前還要密封、不得在日拆用。**轉售不合資格**（Donki 官網） | 走 **輸出免稅**（出口申報、商業發票、裝箱單）。店頭旅客免稅**不是**這條 |
| 2025-04-01 起 | 自己用國際包裹／代運把免稅貨寄走，**不能再憑託運單證明資格**；必須人帶出境、海關抽查時出示 | 商業出口本來就不是旅客免稅 |
| 2026-11-01 起 | 店頭改付含稅價、出境後退款；消耗品分類與密封制廢止。確認以**一張收據為單位**——少一件，整張不退 | 不適用 |
| 加拿大 CBSA | 個人自用、偶爾超量會被當商業貨重估 | 商業進口：進口人、商業發票、HS、GST；化妝品要 CNF；防曬要 NPN／DIN |
| 發票 | 免稅常**不開可作進貨的發票**（Donki：免稅不開發票） | 要商業發票；香港轉口若發票在非 CPTPP 方開出，CoO 必須**與發票分開** |

用旅客免稅當批發，是濫用日本制度，也是加拿大商業進口偽裝成手信。兩邊都查得到。

### 4. 代運：Tenso / Buyee（及 Rakuten Global Express）

費堆疊（同一件貨從日本網店到香港或加拿大，常見層）：

1. 商品價（含 10% 消費稅，除非真的出口免稅——代運客單幾乎沒有）  
2. 日本國內運到代運倉（Buyee 官方常見 **¥150–1,500／件**；「賣家免運」仍可能因要可追蹤運單而被改成收費）  
3. 代購／代標費：Buyee **¥500／單**；Tenso 自購自寄則無代購費、有倉租／作業費  
4. 集運／加固／拍照（可選）  
5. 國際運費（EMS／AIR／DHL／海運）。Tenso 官網計算機含加拿大、香港。RGX 示例香港 1.8 kg 級已 **¥4,000+**  
6. 目的地關稅、GST、經紀（加拿大 de minimis **CAD 20**，萬寧式客單幾乎必超）

| 欄 | 內容 |
| --- | --- |
| 渠道 | **Tenso：** 自購 → 寄 Tenso 倉 → 集運出海。歷史最長的日→世界轉運之一。**Buyee：** 同一集團（tenso Inc.）的代標／代購，主打雅虎拍、Mercari、沒海外配送的店。**RGX：** 樂天官方集運，店舖件為主，不收 C2C。 |
| 擅長 SKU | 日本網店有、店頭當天拿不到的貨。不擅長把 CAD 21 貨做成有貢獻的加拿大零售單。 |
| 相對萬寧 | 費堆疊之後，多數藥妝 **輸給香港週採**。只有日本網價極端低、或香港徹底沒貨時才贏。 |
| MOQ／實務門檻 | 1 件。實務門檻是**集運到一個夠重的箱**（8–12 kg 空運帶，與全盤生存條件相同）。單件直出加拿大 = 自殺。 |
| 發票與原產地 | 代運商業發票是「一箱雜貨、價值申報」；**不是**生產商 CoO。海關看到的是轉運商，不是松本清。 |
| 消費稅 | 已付的 10% 通常拿不回。不要把代運當成輸出免稅。 |
| 真貨 | 等於上游。Tenso／Buyee 不保證雅虎拍真偽。 |
| 摩擦 | 液體、噴霧、電池、100V 電器限制。加拿大 GST 在清關。DDU 轉換差；DDP 要你墊。直寄加拿大的經紀費單獨就能吃掉一件毛利。 |
| 筆記 | 代運是**日本網店 → 香港週箱**的膠水，不是「開給溫哥華客人的物流產品」。 |

**Super Delivery：** B2B 平台，時尚／雜貨／文具為主（Kokuyo、Zebra 有出現），標榜小量、海外買家可註冊看批發價。Health & Beauty 分類存在，但**不是** SK-II／資生堂／花王授權出口。適合探文具／雜貨小單；**不要**指望這裡開到目錄英雄護膚的批發價。運費與供應商 MOQ 各異，常仍要日本地址或指定貨代。

## 香港 vs 日本：決策樹

公式在 01；這裡只寫觸發。目錄中位賣價 CAD **24**，平均毛利約 **52%**。一件一寄 DHL 在 Melano（landed 9.60／賣 21）上會把貢獻打到 0 或負。生存條件仍是**每週 8–12 kg 集運**。

```
SKU 在加拿大能不能合法商業賣？
 ├─ 防曬／NHP／眼藥水／美白口服 → 公司不賣。人可以自己買。停。
 ├─ 100V 電器 → 預購 + 警告，或砍。見下。
 └─ 普通化妝品／頭髮／文具
      │
      香港本週貨架有、促銷後落地 ≈ 目錄 landedCad？
       ├─ 有 → 留萬寧。不要為 10% 日本消費稅飛。
       └─ 沒有／日版限定／日本大減
            │
            把日本店頭稅拔價 ÷ 108，加上：
            行李箱攤分 或（代運國內運 + 作業 + 國際段到香港），
            再加香港→YVR 集運均攤 CAD 2–5／件，
            再加 GST 5%（DDP 你墊），
            再加 MFN 6.5%（沒有 CoO 就付；CAD 12 貨 ≈ CAD 0.80）
            │
            這條落地 < 香港同週落地，且差距大過斷貨成本？
             ├─ 是，且是文具限定／Hobonichi／開架斷貨 → 日本行或 JP 網單→香港倉。
             ├─ 是，且是 SK-II 230 ml／Decorté → 可以為日本出口發票 + 可能的 CoO 走一趟。
             └─ 否 → 留香港，或缺貨預購等到下週萬寧。
```

**觸發日本、用文字講落地：**

- **不要觸發：** Hada Labo 化妝水目錄 landed CAD 11.50。日本稅拔即使是 ¥1,000（≈ CAD 9.26）再免稅，看起來省 CAD 2。代運或機票攤到每支 CAD 3–8，加拿大段再 CAD 2–5，**已經輸**。萬寧週促時更輸。  
- **觸發：** Hobonichi Weeks 英語版（目錄 landed 28／賣 52，季節預購）。香港沒有同期。日本官方／Hands／Loft 現貨 → 網單集運香港，或人帶。  
- **觸發：** SK-II 230 ml landed 148／賣 248。日本免稅店頭若能到稅拔約 ¥15,000–16,000（desk 回推批發約 ¥9,900，店頭會高一截），10% 消費稅 ≈ CAD 14；再加 6.5% MFN ≈ CAD 10。這量級才開始讓「日本出口文件」有數學意義。仍要集運，仍不要一件 DHL。  
- **永遠不觸發：** 為了 CPTPP 去日本買 CAD 10–20 貨。見下一節。

機票不是 COGS。一趟東京若只帶回 8 kg 藥妝，機票可以把「看起來平的免稅」全部吐回去。日本行要疊在本來就要去的行程，或一次帶夠週集運的量。

## CoO、發票、消費稅

### 日本消費稅：兩條完全不同的路

| | 旅客免稅（消費税免税） | 輸出免稅 |
| --- | --- | --- |
| 給誰 | 非居民個人 | 出口貨物的事業者 |
| 證據 | 護照／VJW QR、店頭紀錄、出境出示 | 出口申報、商業發票 |
| 轉售 | **不行**（Donki 寫明） | 這才是生意 |
| 2025-04-01 | 自己郵寄不能再當證明 | 無關 |
| 2026-11-01 | 店頭含稅、出境退；密封制廢 | 無關 |

Year 1 你走的是左欄偽裝成進貨，或付 10% 當國內零售再運走。右欄要日本出口身分——你還沒有。

### CPTPP：誰能簽、旅客袋為什麼沒有

加拿大與日本都是 CPTPP 成員；**香港不是**。HS 3304 化妝品 MFN 常見 **6.5%**；日本產、符合原產規則、有證明 → 可 0%。

GAC／CBSA（D11-4-14、GAC CPTPP 頁）：

- CoO **沒有法定表格**，最低資料集（Annex 3-B）可寫在發票或另紙。  
- **出口商、生產商、或進口商**都可以完成證明。  
- 進口商自簽的前提：你**有文件證明貨是原產**，或合理依賴出口商／生產商文件。CBSA 查核時你要拿得出來。加拿大要留紀錄 **6 年**。  
- 簽署人須有權代表公司、且對原產有足夠知識。  
- 發票若在**非締約方**開出（香港公司開給加拿大客人的發票），CoO 必須與發票**分開**。  
- 商業貨完稅價格 ≤ **CAD 3,300** 時，**可以不附** CoO，但進口人仍須保留能證明符合原產規則的紀錄。把一週的貨拆成多票來躲門檻，可被當成一系列出口而要求正式證明。  
- 另：海關價值 < CAD 1,600 的 CPTPP 貨，GAC FAQ 寫一般不強制 CoO——同樣**不代表**你可以在沒有原產知識時亂填優惠稅率。

**旅客袋沒有 CoO。** 松本清收據證明你付了錢，不證明原產規則、生產商地址、HS 6 位、原產標準。進口商拿着藥妝店收據自簽「我證明這是日本原產 CPTPP 貨」，查核時拿不出生產紀錄，就是錯誤申報。

### 什麼時候追 CoO 才打得過 6.5%

| 貨 | 目錄 landed | 6.5% MFN | Year 1 要不要追 CoO |
| --- | ---: | ---: | --- |
| Melano CC | 9.60 | **CAD 0.62** | **不要。** 律師／時間／出口商關係遠貴過 62 仙。 |
| Hada Labo 170 ml | 11.50 | **0.75** | 不要。 |
| Fino 髮膜 | 8.10 | **0.53** | 不要。文具更不要（多數本來就低關稅）。 |
| Decorté Liposome | 86 | **5.59** | 有日本出口發票再說；沒有就付 MFN。 |
| SK-II 230 ml | 148 | **9.62** | 唯一接近「值得」的目錄貨。仍要出口商肯簽，或你有能力在查核時出示原產文件。Year 1 通常仍是付 6.5%。 |

**通常永遠不要為 CAD 10–20 的貨追 CoO。** 這不是懶，是算術。公司稅差每件約 CAD 0.34；MFN 6.5% 在這層也是同一數量級。兩者都不該驅動渠道選擇。

香港轉口：貨仍是日本產、未經實質加工，理論上原產可以保留，但平行進口商手上通常**沒有**日本 CoO → 實務付 MFN。不要計劃「經香港就能自動 CPTPP」。

## 100V／PSE vs CSA：不要軟話

日本電器在日本銷售要吃 **PSE**（《電氣用品安全法》／DENAN）：指定品菱形第三方、非指定品圓形自律。這是**日本國內**的標。JQA／METI 寫得很清楚：義務在日本製造商／進口商。

加拿大零售電器要的是 SCC 承認的認證標（CSA、cUL 等）。**PSE ≠ CSA。**  
**SPE-1000** 是加拿大現場評估（field evaluation）給客製、小量、沒有完整認證路徑的設備——工業機、進口成套線。**不是**給你把 ReFa 夾、YA-MAN 頭皮刷、Panasonic Nanoe、SALONIA 一箱一箱當零售 SKU 賣的捷徑。一次 SPE-1000 的錢，就能買光 Year 1 電器毛利。

目錄工具：

| SKU | landed／賣 | 筆記 |
| --- | ---: | --- |
| ReFa BEAUTECH | 168／289 | 100V。保固日本境外當無。 |
| YA-MAN Mysé | 92／168 | 100V。 |
| Panasonic EH-NA0J | 118／199 | 100V，轉接頭不是變壓。 |
| SALONIA 24 mm | 38／72 | 100V。 |
| MaPEPE／Ikemoto 梳 | 6.4／16、5.8／15 | 非電，可留。 |

120V 北美插 100V 機：多半能轉、更熱、更易壞、有過熱風險。Adaptor 只改插頭形狀。

**決策：預購 + 明確 100V／非 CSA 警告，或從商業目錄砍掉。** Year 1 建議砍。桌上模型工具電器約 CAD 31k GMV——拿掉以後活得比較像合法生意。不要寫「客人自己注意電壓」然後當普通現貨賣。
